# Movete Fácil Driver

Esta es la **aplicación independiente de conductores y repartidores**. Solo ejecuta demostraciones locales mientras se certifican Auth, documentación privada, elegibilidad y despacho.

Instalación local: `npm install`; pruebas `npm run check`; vista Expo `npm start`. Paquete Android/iOS: `com.movetefacil.driver`.

**No incluye** solicitudes del pasajero, panel administrativo ni llaves de servidor. Los documentos definitivos residirán en almacenamiento privado del backend, no únicamente en el celular.
